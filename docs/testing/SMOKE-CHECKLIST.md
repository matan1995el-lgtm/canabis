# 🧪 SMOKE-CHECKLIST — בדיקות עשן ידניות בדפדפן (TASK-012)

> להרצה לפתיחת `index.html` בדפדפן (או דרך `python3 -m http.server`).
> מטרה: אימות מהיר אחרי כל שינוי — ~5 דקות.
> שער אוטומטי מקביל: `sh ./scripts/check.sh` (ST-01/02/03).

## 1. ניווט טאבים (FINDING-002 / TASK-003)

- [ ] רק טאב אחד גלוי בכל רגע נתון
- [ ] מעבר בין 4 הטאבים עובד (ניהול / סטטיסטיקות / חיפוש / הגדרות)
- [ ] כפתור הטאב הפעיל מסומן ויזואלית

## 2. סנכרון ענן (TASK-002)

- [ ] חיווי הסנכרון מציג "מתחבר..." ואז "מחובר לענן" (או הודעת שגיאה ברורה אם Anonymous auth כבוי ב-Console)
- [ ] לאחר חיבור — אין node `connection_test` חדש ב-Firebase Console
- [ ] הנתונים נשמרים תחת `strains/{authUid}` (uid אמיתי, לא `user_...`)

## 3. הוספת זן

- [ ] "פתח טופס הוספה מלא" פותח את המודל; הפוקוס נופל על שדה "שם הזן"
- [ ] הוספת זן חדש עובדת והשורה מופיעה בטבלה
- [ ] ESC סוגר את המודל; הפוקוס חוזר לכפתור הפתיחה

## 4. עריכת זן (TASK-009 — חדש)

- [ ] כפתור ✏️ בשורת זן פותח את המודל במצב "ערוך זן" עם הערכים המלאים
- [ ] שינוי שדה + שמירה מעדכן את השורה in-place (ה-id/createdAt נשמרים)
- [ ] סגירת המודל מאפסת חזרה למצב "הוסף זן חדש"

## 5. מחיקה וגיבוי (TASK-004 / FINDING-011 — חדש)

- [ ] מחיקת זן בודד: confirm אחד + השורה נעלמת
- [ ] "מחק את כל הנתונים" עם נתונים קיימים: מציע גיבוי JSON לפני האישור הסופי
- [ ] הגיבוי שהורד מכיל את כל הזנים שהיו לפני המחיקה

## 6. מצב כהה (TASK-010 — חדש)

- [ ] הפעלת המצב הכהה ואז רענון דף — המצב נשמר
- [ ] כיבוי ורענון — חוזר לבהיר
- [ ] ה-checkbox בהגדרות מסונכרן עם המצב בפועל בטעינת הדף

## 7. חיפוש (TASK-006 / FINDING-016/017)

- [ ] חיפוש על שם/סוג/טרפנים עובד
- [ ] תוצאה עם תווים מיוחדים (למשל `<b>` בשם זן) אינה מרונדרת כ-HTML
- [ ] אין קריסה כאשר rating חסר/שגוי בנתונים

## 8. סטטיסטיקות (TASK-007 / FINDING-006/010)

- [ ] הטאב "סטטיסטיקות" מציג כרטיסים מספריים
